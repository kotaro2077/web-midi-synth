# Web MIDI Synth

USB MIDIキーボードをChrome／Chromiumから演奏できる、無料のブラウザMIDIシンセサイザーです。

A free browser-based MIDI synthesizer using the Web MIDI API and Web Audio API.

## 🎹 Live Web App / Webアプリ

### [▶ Open Web MIDI Synth / ブラウザで開く](https://kotaro2077.github.io/web-midi-synth/)

No installation required. MIDI input and audio output devices can be enabled and selected independently.

インストール不要です。MIDI入力と音声出力デバイスを個別に選択・有効化できます。

## Features

- USB MIDI keyboard input
- Selectable audio output device
- Chord detection
- Instrument presets
- Sound controls
- Waveform view
- MIDI history view
- Reactive object view
- Light / dark mode

## Run locally

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```
