# Web MIDI Synth

Browser-based MIDI synthesizer using the Web MIDI API and Web Audio API.

## Features

- USB MIDI keyboard input
- Chord detection
- Instrument presets
- Sound controls
- Waveform view
- MIDI history view
- Reactive object view
- Light / dark mode

## Run locally

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Browser

- Google Chrome
- Chromium
